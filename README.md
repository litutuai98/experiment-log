# 实验记录 · Experiment Log

本地运行的实验笔记本：记录每个实验在哪个目录下做、用什么数据和模型、有哪些结果与结论；
同一实验下的变体（有效、无效、部分有效都算反馈）、实验之间的关系、准备写的论文，以及按天整理的日报。

纯 Python 标准库，只监听 `127.0.0.1`，SQLite 保存数据。克隆下来一条命令即可使用。

## 运行

需要 Python 3.10 及以上：

```bash
python3 server.py
```

然后打开 **http://127.0.0.1:8768**。数据保存在 `data/`（首次运行自动创建，不进入版本库）。

指定端口或数据目录：

```bash
PORT=9000 KNOWLEDGE_DATA_DIR=/path/to/data python3 server.py
```

## 功能

- **实验卡片**：目录、数据（数据集与划分）、模型与关键设置、结果、结论、相关路径。
- **变体**：同一实验下的不同尝试，标记有效 / 无效 / 部分有效 / 待定，并记录反馈与路径。
  无效的尝试同样是重要反馈。
- **实验关系**：基于 / 对照 / 共用数据或模型 / 相关，可带备注。
- **论文**：阶段（构思、写作、投稿、录用、发表）、预计投哪里、截止日期、依据哪些实验、用到哪些结果。
- **按天记录**：所有记录按日期归档，切换日期会同时切换实验下的当天记录、"未归类"记录和右侧日报。
- **自然语言整理**：用一段话写下今天做了什么，配置 AI 后自动分配到对应实验；分配结果先给你确认，可修改后再保存。
- **日报**：自己写，或根据当天记录生成草稿，AI 可进一步总结。
- **图片与附件**：截图可以直接粘贴（⌘V）、拖入或选择文件，在顶部输入框、实验卡片和新建实验表单里都能用；也可以先放在「未归类」，之后再归到实验里。
  结果表格的截图会被读图模型逐格抄成可编辑表格，可一键写入实验「结果」；模型结构图、曲线图默认保存为图片并附一句说明；PDF 原样保存为附件，在浏览器里打开。
  读图默认使用「AI 设置」里的模型（如 `deepseek-flash`），也可以在右侧「图片解析模型」里单独配置 OpenAI 兼容或 Anthropic 接口的读图模型；没配置时图片照样保存，之后可再转成表格。
- **图文混排**：编辑实验时，数据、模型、结果、结论、相关路径、备注这些文字框都能直接粘贴（⌘V）、拖入或插入图片，图片插在光标处并配一句说明，和文字一起保存；查看时图片出现在原来的位置。
- **中英切换**：界面语言可在顶栏切换，英文界面不残留中文文案（用户输入除外）。

AI 功能使用你在「AI 设置」里配置的模型；不配置也可以手动记录。

## 目录结构

```
server.py            入口
deskcore/            共享内核（HTTP、SQLite、AI 调用、静态资源）
desk_lab/            实验记录的领域逻辑与接口
static/              页面与前端脚本
tests/               回归测试
data/                本机数据：数据库和 lab-figures/ 下的图片附件（自动创建，不进入版本库）
```

`deskcore` 是本地知识工作台的内核快照；实验记录作为独立项目只用到其中的通用能力
（HTTP 服务、SQLite、AI 请求、任务队列、样式）。后续同步方式：用新版内核替换
`core/deskcore/` 即可，项目代码与数据格式保持不变。

## 数据与隐私

- 所有内容只保存在本机 `data/` 的 SQLite 数据库里；服务只监听 `127.0.0.1`，
  并校验请求来源，外部网页无法调用。
- 仓库不包含任何个人数据；别人克隆后首次运行会自动新建空数据库。
- "导出 / 备份"：直接复制整个 `data/` 目录即可。
